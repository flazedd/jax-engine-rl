# Archive

Historical record, kept because it explains *why* things are as they are, not
how they work now.

- `milestones/` — the M0–M7 milestone specifications the project was built
  against. The repository is now organised by the structure of the thesis
  rather than by the order the work happened, so these describe a scheme that
  no longer maps onto the code. They remain the best account of the
  environment-design iterations (E0–E6e) and of why several designs were
  rejected.

For how the project works now, see `docs/pipeline.md` and the navigation table
in `CLAUDE.md`.
